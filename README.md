# Время рядом

Городская афиша: просмотр мероприятий, фильтры, запись и избранное, создание своих событий с фото и отменой.

## Стек

| Слой | Технологии |
|------|------------|
| Backend | Python 3.10+, Flask |
| Шаблоны | Jinja2 |
| БД | SQLite (`vremya.db`) |
| Frontend | HTML, CSS, небольшой JS (тема) |
| Auth | сессии Flask + хеши паролей Werkzeug |

Зависимости перечислены в `requirements.txt`:

- `flask>=3.0`
- `werkzeug>=3.0`

## Архитектура

```
vremya/
├── main.py                 # приложение Flask, маршруты, инициализация БД
├── vremya.db               # SQLite (создаётся при первом запуске)
├── requirements.txt
├── start.bat / start.sh    # скрипты запуска
├── static/
│   ├── css/style.css
│   ├── js/theme.js
│   ├── img/placeholders/   # SVG-заглушки по категориям
│   └── uploads/            # загруженные фото мероприятий
└── templates/
    ├── base.html
    ├── index.html, afisha.html, event.html, ...
    └── partials/event_card.html
```

### Модель данных

- **users** — телефон, имя, фамилия, хеш пароля
- **events** — название, категория, дата/время, место, описание, места, автор, фото, флаг отмены
- **registrations** — запись пользователя на мероприятие
- **favorites** — избранное

При старте `init_db()` создаёт таблицы (если их нет), при необходимости добавляет колонки `image` и `cancelled`, наполняет демо-данные и назначает заглушки фото существующим событиям без картинки.

### Основные маршруты

| URL | Назначение |
|-----|------------|
| `/` | Главная, ближайшие события |
| `/afisha` | Афиша с поиском и фильтрами |
| `/event/<id>` | Карточка мероприятия |
| `/create` | Создание мероприятия (с фото) |
| `/event/<id>/cancel` | Отмена своего мероприятия |
| `/event/<id>/register` | Запись |
| `/cabinet` | Личный кабинет |
| `/login`, `/register` | Вход и регистрация |

Отменённые мероприятия скрываются из афиши и главной, но остаются в кабинете автора с пометкой «Отменено».

## Запуск

Нужен **Python 3.10+**.

### Через скрипт

**Windows**

```bat
start.bat
```

Двойной клик по `start.bat` или запуск из cmd/PowerShell в папке проекта.

**macOS / Linux**

```bash
chmod +x start.sh
./start.sh
```

Скрипт создаст `.venv` (если нет), установит зависимости и запустит сервер.

Откройте в браузере: [http://127.0.0.1:5000](http://127.0.0.1:5000)

### Вручную

**Windows (PowerShell / cmd)**

```bat
cd путь\к\vremya
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

**macOS / Linux**

```bash
cd путь/к/vremya
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Остановка: `Ctrl+C`.

## Возможности

- Афиша с поиском, фильтром по категории и дате, сортировкой
- Карточки мероприятий: **3 в ряд** (на планшете 2, на телефоне 1)
- Запись на событие и избранное
- Создание мероприятия с необязательным фото (PNG/JPG/WEBP/GIF, до 5 МБ)
- JPG-заглушки по категориям для событий без своего фото
- Отмена мероприятия автором (из карточки или кабинета)
- Светлая / тёмная тема
